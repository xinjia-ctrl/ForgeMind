# 已知限制

- 仅支持一次运行修改一个本地 Git 仓库。
- 不提供多仓库依赖图、PR 创建、自动 push 或自动 merge。
- 不监听 GitHub、Jira 或 CI；需求必须由用户主动提交。
- 不提供长期记忆、向量检索或跨项目 RAG。
- 所有阶段默认使用同一个模型和供应商。
- 模型输出仍可能错误；TEST 与 REVIEW 降低风险，但不能证明没有缺陷。
- 容器模式依赖宿主机 Docker/Podman；本地模式不是强隔离。
- 关闭网络的容器无法在运行中下载依赖，目标仓库需提前准备依赖。
- 只支持非 detached HEAD、已有初始 commit、且运行前干净的工作区。
- 恢复要求原分支与运行清单完全匹配，不支持迁移到另一台机器后无条件继续。
- 本地 Web 工作台不是公网服务，不提供登录、多人协作或服务端凭据管理。
- OpenAI-compatible 供应商可能改变模型名或协议细节，需要维护供应商目录与兼容测试。
- Prompt injection 防护基于信任标签、结构化边界和工具策略，不是形式化安全证明。
- 主要 CI 环境为 Ubuntu + Node.js 22，不宣称所有操作系统行为一致。
