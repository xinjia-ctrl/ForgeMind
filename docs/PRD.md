# ForgeMind 产品说明

## 1. 定位

ForgeMind 是一个本地、单仓库 AI 编码 Agent。用户提供仓库与需求，系统在独立 Git 分支中完成计划、编码、测试、审查和提交，并留下可回放证据。

它解决的核心问题不是“让模型写一段代码”，而是“如何让模型修改真实仓库后，用测试、审查和策略证明结果可接受”。

## 2. 目标用户

- 希望演示 Agent 工程闭环的开发者。
- 需要在本地仓库安全试用 AI 编码的个人或小团队。
- 想研究工具调用、状态机、验收门禁与故障恢复的工程人员。

## 3. 核心需求

1. 输入仓库路径和自然语言需求即可启动。
2. 工作区不干净时拒绝运行；每个 Run 使用独立分支。
3. 模型输出必须符合阶段结构，工具调用必须通过策略。
4. TEST 与 REVIEW 都通过后才能提交。
5. 门禁失败后把累计证据返回 CODE，限制返工次数。
6. 运行中断后可以从安全检查点恢复。
7. 事件、预算、审批和产物可以离线查看。
8. 支持常见 OpenAI-compatible 供应商，默认 DeepSeek V4.1 Flash。

## 4. 非目标

- 多仓库并行编排和自动合并。
- GitHub、Jira、CI Webhook 或轮询服务。
- 长期记忆、向量数据库和跨项目 RAG。
- Agent 自由协商、动态创建角色或工具。
- 公网托管、多人实时协作和凭据托管。

## 5. 成功标准

- 代表性任务可以产生真实代码、通过真实测试并创建 commit。
- 任一验收证据缺失时不能进入 COMMIT。
- 策略拒绝、预算耗尽、模型失败和中断都有明确状态与事件。
- 相同输入与固定 Fake Provider 产生相同工作流签名。
- `npm run check` 全量通过。

## 6. 主要模块

| 模块                         | 责任                                         |
| ---------------------------- | -------------------------------------------- |
| `src/core`                   | 状态机、上下文、事件、检查点、预算、验收契约 |
| `src/agents`                 | PLAN、ARCH、CODE、TEST、REVIEW、COMMIT 阶段  |
| `src/tools`                  | 文件、搜索、命令与 Git 工具及统一执行器      |
| `src/policy` / `src/sandbox` | 权限决策、人工批准和隔离执行                 |
| `src/llm`                    | 模型供应商目录和 OpenAI-compatible 调用      |
| `src/report` / `src/web`     | 离线报告和本地操作界面                       |
